# 课程助教微信小程序

一个开放式的课程资源学习和学习问答微信小程序，为学习者提供便捷的课程资料管理和学习交流平台。已配置微信云开发，支持数据持久化和云端部署。

## 功能特性

### 🎯 核心功能
- **课程资源**: 浏览开放式的课程学习资源，包括教材、视频、课件等
- **作业练习**: 自主练习和完成课程作业，跟踪学习进度
- **学习问答**: 提问和回答学习问题，与其他学习者交流
- **成绩统计**: 查看个人学习进度和完成情况

### 📱 界面特点
- 现代化UI设计，简洁美观
- 响应式布局，适配各种设备
- 流畅的动画效果和用户体验
- 直观的数据可视化

## 快速开始

### 1. 本地开发（推荐初学者）

```bash
1. 打开微信开发者工具
2. 导入项目目录：e:\codebuddy
3. 点击"预览"用手机扫码查看
4. 开始体验功能
```

### 2. 云开发配置

项目已配置好云开发，只需要简单几步：

```bash
1. 打开微信开发者工具
2. 点击"云开发"开通云开发（基础版免费）
3. 复制环境ID并填入 app.js
4. 上传云函数
5. 创建数据库集合
```

详细配置步骤请查看：[云开发快速开始.md](./云开发快速开始.md)

### 3. 运行项目
1. 打开微信开发者工具
2. 导入项目目录
3. 点击编译运行
4. 在模拟器或真机中查看效果

## 云开发说明

### 已配置的云功能

#### 云函数（2个）
- **getCourses**: 获取课程列表
- **saveCourse**: 保存课程信息

#### 云数据库（2个集合）
- **courses**: 课程信息表
- **homeworks**: 作业信息表

#### 免费额度（每月）
- 数据库读写：80,000次
- 存储空间：5GB
- CDN流量：5GB
- 云函数调用：200,000次
