# 课程助教微信小程序

一个专为教师设计的课程管理微信小程序，帮助教师更好地管理课程、学生和作业。

## 功能特性

### 🎯 核心功能
- **课程管理**: 创建、编辑、管理课程信息
- **学生管理**: 添加、编辑、查看学生信息
- **作业管理**: 发布作业、查看提交情况、批改作业
- **成绩统计**: 学生成绩录入、统计分析和图表展示
- **通知消息**: 发送课程通知、学生互动

### 📱 界面特点
- 现代化UI设计，简洁美观
- 响应式布局，适配各种设备
- 流畅的动画效果和用户体验
- 直观的数据可视化

## 项目结构

```
├── app.js                  # 小程序入口文件
├── app.json               # 小程序配置文件
├── app.wxss               # 全局样式文件
├── project.config.json    # 项目配置文件
├── sitemap.json          # 站点地图配置
├── pages/                # 页面目录
│   ├── index/            # 首页
│   ├── course/           # 课程管理
│   ├── homework/         # 作业管理
│   ├── grade/            # 成绩统计
│   ├── notice/           # 通知消息
│   ├── student/          # 学生管理
│   └── profile/          # 个人中心
├── images/               # 图片资源目录
└── utils/                # 工具函数目录
```

## 技术栈

- **框架**: 微信小程序原生开发
- **语言**: WXML, WXSS, JavaScript
- **开发工具**: 微信开发者工具

## 使用说明

### 环境准备
1. 下载并安装微信开发者工具
2. 创建新的小程序项目
3. 将本项目代码复制到项目目录

### 运行项目
1. 打开微信开发者工具
2. 导入项目目录
3. 点击编译运行
4. 在模拟器或真机中查看效果
